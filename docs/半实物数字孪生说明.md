# FBG 半实物数字孪生：无新增实验方案说明

## 1. 方案定位

本工程把真实温度光谱与物理仿真的应变效应结合起来。真实部分包括四通道谱形、温度灵敏度、仪器噪声和背景纹波；仿真部分包括光弹应变位移以及假设的非均匀应变展宽。

该方案可以用于论文仿真复现、方法比较和可行性分析，但不能替代真实应变实验验证。

## 2. 已实现的数据链路

1. 从 40 个 `.list` 文件读取 45–84.3 °C 的 CH1–CH4 光谱。
2. 对齐四通道主峰并建立真实光谱模板与残差噪声库。
3. 使用光弹关系生成 0–900 µε 的中心波长变化。
4. 使用真实残差进行噪声域随机化。
5. 分别训练单通道论文六特征模型、四通道特征融合模型、物理引导两阶段模型和四通道 CNN。
6. 使用完整工况留出评估，并用真实温度光谱进行零应变一致性检查。

## 3. 关键物理发现

四通道温度灵敏度约为 9.48–10.21 pm/°C，理论应变灵敏度约为 1.20–1.21 pm/µε。两类灵敏度向量夹角只有约 1.52°，接近共线。因此，单纯用四个峰位联立反演会严重放大寻峰误差，不能作为可靠解法。

在保守的 3.5% 非均匀应变假设下，谱形变化容易被真实噪声淹没。8% 假设可以提高应变可辨识性，但该数值没有实验标定，只能作为敏感性场景，不能写成真实传感器参数。

## 4. 正式 8% 假设场景结果

完整工况留出测试中，四通道特征融合的应变 R² 约为 0.939，温度 R² 约为 0.423。物理引导模型回测真实温度光谱时，温度 R² 约为 0.846、MAE 约为 4.16 °C，零应变参考的平均误判约为 41 µε。

四通道 CNN 在半实物测试集上没有显著超过传统模型，并在真实温度谱上出现明显域偏移。因此不应使用其仿真分数宣称真实传感性能。

## 5. 可以写进大创报告的结论

- 已完成论文式六特征与四种集成回归算法复现。
- 已利用真实温度光谱建立四通道标定和半实物数字孪生数据集。
- 证明了仅靠中心波长时温度与应变存在严重可辨识性问题。
- 证明了旁瓣、峰宽和多通道融合可以提供额外信息，但结果依赖未标定的应变传递假设。
- 给出了仿真到真实迁移失败的定量证据，避免把仿真准确率误写成实验准确率。

## 6. 仍缺少的证据

若要声称真实温度—应变解耦有效，仍需真实应变标签、公开数据集或作者原始数据中的至少一种。没有这些证据时，最严谨的项目名称是“基于实测温度光谱校准的 FBG 温度—应变解耦数字孪生与可辨识性研究”。
