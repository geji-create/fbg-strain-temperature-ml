# GitHub 发布范围

本仓库定位为可公开阅读和复现的代码版本，包含源码、配置、测试、方法说明、核心指标以及论文级结果图。

以下内容仅保存在本地，不进入公开 Git 历史：

- Python 虚拟环境和缓存；
- 原始实验压缩包、四通道原始光谱和大体积仿真光谱；
- PyTorch 与 scikit-learn 模型权重；
- 受版权保护的论文 PDF；
- 含姓名、学号的 PPT、Word、讲稿与报告生成脚本；
- 旧版文件、渲染缓存和质检目录。

这些排除项不会影响源码审阅。仿真数据和模型可按 `README.md` 中的命令重新生成。第三方公开数据的来源、许可证与 DOI 记录在 `data/external_mendeley_dual_peak/SOURCE.md`。
