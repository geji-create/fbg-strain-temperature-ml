# Publication figures

All figures are exported as PNG, PDF and SVG. PNG files are 300 dpi; PDF/SVG retain vector text and geometry.

- fig01_real_temperature_calibration: real four-channel temperature calibration.
- fig02_split_generalization: random split versus unseen-condition evaluation.
- fig03_pytorch_progression: V1–V3 improvements and cross-solver validation.
- fig04_ablation_position_shape: three-seed ablation results with uncertainty.
- fig05_position_shape_mechanism: new data-driven mechanism figure using V3 spectra.

Additional figures generated by process_external_dual_peak_dataset.py:
- fig06_external_dual_peak_dataset: third-party measured spectral behaviour.
- fig07_external_temperature_benchmark: sensitivity comparison and LOOCV calibration.

Color semantics: blue = key method, green = improvement, red = contrast, gray = baseline.
